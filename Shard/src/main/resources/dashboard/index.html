Access management

Player permissions

Set persistent allow or deny overrides for registered permission nodes on online players.

Choose a player and permission to inspect its effective value.

Overrides are stored in the Shard configuration and applied while the player is online, including after reconnects. Other permission plugins may also manage permissions; review their rules if the effective result differs.

Server settings

Safe configuration

Edit only the dashboard listener and Shard message prefix.

Bind address and port changes are saved immediately but take effect after the server or plugin restarts. Use a literal IPv4/IPv6 address assigned to this server, or 0.0.0.0 for all IPv4 interfaces. The license key is never read or exposed by this editor.
